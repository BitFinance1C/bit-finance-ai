# Скиллы ИИ для БИТ.ФИНАНС

В этой папке лежат файлы скиллов (навыков) для искусственного интеллекта, которые можно загрузить в программу **БИТ.ФИНАНС** на платформе 1С.

## Что здесь лежит?

Каждый скилл — это отдельный файл в формате JSON. Имя файла совпадает с идентификатором (id) скилла. Например, скилл с id `get_budget` хранится в файле `get_budget.json`.

**Особый случай:** если у скилла вид обработчика — **«Внешняя обработка»**, то рядом с JSON-файлом может находиться одноимённый файл с внешней обработкой для 1С (расширение `.epf`). Например, `my_skill.json` и `my_skill.epf`.

Вид обработчика может принимать значения:

- «Внешняя обработка»
- «Отчет»
- «Произвольная процедура»

Эта информация указана внутри JSON-файла скилла.

## Файл `index.json` — каталог всех скиллов

В этой папке есть файл **`index.json`** — это «каталог» всех скиллов. В нём перечислены все скиллы с их id, названиями, описаниями и именами файлов.

Этот файл используется программой 1С для автоматического получения списка доступных скиллов: пользователь видит список с описаниями, выбирает нужный и скачивает только его, не выгружая весь архив целиком.

**Если вы добавляете новый скилл — не забудьте добавить запись о нём в `index.json`.** Формат записи и примеры — в файле `CONTRIBUTING.md` в корне репозитория.

## Правила именования файлов

- Имя файла = id скилла.
- Используйте латинские буквы, цифры и подчёркивания (`_`). Без пробелов и специальных символов.
- Примеры: `find_client.json`, `get_object_id.json`, `last_order.json`.

## Как использовать эти файлы?

1. Скачайте нужные файлы:
   - **Весь набор сразу:** нажмите зелёную кнопку **Code** → **Download ZIP** в корне репозитория.
   - **Отдельный файл:** откройте его и нажмите кнопку **Raw**, затем сохраните страницу.
2. Загрузите скилл в БИТ.ФИНАНС через справочник **«Навыки»** (используйте кнопку загрузки навыка).

## Как предложить свой скилл?

1. Создайте скилл в БИТ.ФИНАНС в справочнике **«Навыки»**.
2. В форме элемента нажмите кнопку **«Выгрузить навык»** — программа создаст нужные файлы (`.json` и, при необходимости, `.epf`).
3. Убедитесь, что имя файла совпадает с id скилла (см. правила выше).
4. Добавьте файлы в эту папку (`data/skills/`) и не забудьте добавить запись о скилле в `index.json`.
5. Отправьте изменения через механизм **Pull Request**. Подробная пошаговая инструкция — в файле `CONTRIBUTING.md` в корне репозитория.
6. После проверки и одобрения ваш скилл появится в общем наборе.

# AI-материалы для БИТ.ФИНАНС

Этот репозиторий — коллекция готовых материалов для работы с искусственным интеллектом в программе **БИТ.ФИНАНС** на платформе 1С. Здесь собраны скиллы (навыки), шаблоны промптов и описания настроек ИИ-агентов, которыми можно пользоваться и делиться с другими.

## Что здесь есть?

Материалы упорядочены по папкам:

- **`data/skills/`** — скиллы (навыки) ИИ. Каждый скилл — отдельный JSON-файл; для некоторых скиллов рядом может лежать файл внешней обработки `.epf`. Подробнее — в `README.md` внутри этой папки.
- **`data/prompts/`** — шаблоны промптов (готовые текстовые запросы) для ИИ. Каждый шаблон — отдельный JSON-файл с наименованием, кратким описанием, метками и самим текстом промпта. Подробнее — в `README.md` внутри этой папки.

В будущем здесь также появятся:
- описания настроек ИИ-агентов.

Они будут лежать в отдельных папках. Следите за обновлениями!

## Как использовать материалы?

Все файлы находятся в открытом доступе. Чтобы скачать их, **не нужна регистрация на GitHub**:

- **Весь набор сразу:** нажмите зелёную кнопку **Code** → **Download ZIP** вверху страницы. Скачается архив со всеми материалами.
- **Отдельный файл:** откройте нужный файл, нажмите кнопку **Raw**, затем сохраните страницу (или скопируйте содержимое).

После скачивания файлы можно использовать в БИТ.ФИНАНС:

- для **скиллов** инструкция по загрузке есть в `data/skills/README.md`;
- для **шаблонов промптов** инструкция по загрузке есть в `data/prompts/README.md`.

Кроме того, в БИТ.ФИНАНС есть встроенная загрузка материалов прямо из этого репозитория — из карточки скилла или промпта можно открыть список доступных материалов, выбрать нужный и скачать его, не покидая программу.

## Как предложить свои материалы?

Мы рады новым скиллам, шаблонам промптов и настройкам! Если вы хотите поделиться своими наработками:

1. Создайте материал в БИТ.ФИНАНС:
   - для скиллов — через справочник «Навыки» и кнопку «Выгрузить навык»;
   - для шаблонов промптов — через справочник «Шаблоны промптов ИИ» и кнопку «Выгрузить промпт в файл».
2. Убедитесь, что файлы соответствуют правилам именования (для скиллов — см. `data/skills/README.md`, для промптов — см. `data/prompts/README.md`).
3. Добавьте файлы в нужную папку репозитория и не забудьте добавить запись о новом материале в `index.json` соответствующей папки.
4. Отправьте изменения через механизм **Pull Request**. Подробная пошаговая инструкция — в файле `CONTRIBUTING.md` в корне репозитория.

Если вы не знакомы с GitHub, это не проблема: в `CONTRIBUTING.md` описаны простые шаги, а если что-то останется непонятным, вы всегда можете обратиться в поддержку БИТ.ФИНАНС.
